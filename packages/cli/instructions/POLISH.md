# 문장 다듬기 지침 (POLISH v1)

이미 작성된 일자별 노트의 **문장 품질**을 다듬는 패스. 내용 추가·삭제 없이 표현만 고친다.

- 기술 내용은 간결한 research-log 문체로. 번역투 문장("~하도록 하였다", "~할 수 있었다") 제거.
- `결정:` `원인:` `확인` `보류` 같은 짧은 마커는 유지한다.
- 수치·파라미터·파일명·식별자를 절대 잃지 않는다.
- 메타서술("AI에게 시켰다", 커밋 해시, 세션 언급)이 남아 있으면 연구자 1인칭 행위로 고쳐 쓴다.
- 형식(`## @` 헤딩 1개, `###` 주제, 한 줄 불릿, FIG 주석)은 그대로 유지한다.
