# 압축 지침 (CONCISE v1)

노트를 화면 1장 분량으로 압축하는 패스. 기준:

| 항목 | 기준 |
|---|---|
| 불릿 길이 | **≤ 110자** (가장 중요) |
| 하루 불릿 수 | ≤ 10 (바쁜 날 ≤ 12) |
| 하루 `###` 주제 | ≤ 4 |
| 하위 불릿 | 금지 (평탄화) |

**남길 것**: 발견, 결정, 근본 원인, 수치·식별자(`BL-xxx`, `9.4 → 1.7 cm` 등).
**먼저 자를 것**: 배경·동기 설명, 반복, 수치 없는 괄호, 부차적 디테일, 사소한 정리 작업.

110자를 넘는 불릿은 두 개로 쪼개지 말고 **핵심만 남겨 한 줄로 다시 쓴다**.
형식(`## @` 헤딩 1개, FIG 주석)은 유지한다.
