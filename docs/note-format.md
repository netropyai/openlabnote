# 노트 포맷 v1 (정본 스펙)

openlabnote의 정본(canonical) 산출물은 **일자별 마크다운 노트**다. 렌더(PNG/PDF)와 업로드는 이 md의 파생물이다.

## 파일 배치

```
<notesDir>/<projectId>/<YYYY-MM-DD>.md
```

- `notesDir`: 사용자가 지정한 노트 보관 폴더 (설정의 `notesDir`)
- `projectId`: 과제 슬러그 (`[a-z0-9][a-z0-9-]*`)
- lint를 통과하지 못한 자동 작성 결과는 `<YYYY-MM-DD>.draft.md`로 저장된다

## 구조

```markdown
## @August 21, 2026

### Topic title
- bullet
- bullet

### Another topic
- bullet

<!-- FIG: /absolute/path/figure.png | 캡션 -->
```

| 요소 | 규칙 | lint |
|---|---|---|
| 날짜 헤딩 | `## @Month D, YYYY` — 파일당 **정확히 1개**, 파일명 날짜와 일치 | H1·H2·H3 (error) |
| 주제 | `### 짧은 제목` — 하루 **≤ 4** | T1 (warn) |
| 불릿 | `- 한 줄` — **≤ 110자**, 하루 **≤ 12**, **하위 불릿 금지** | B1 (error) · B2 (warn) · B3 (error) |
| 그림 | `<!-- FIG: 절대경로 \| 캡션 -->` — **실존 파일만**, 하루 **≤ 3** | F1 (error) · F2 (warn) |
| 내용 | 비어 있으면 안 됨 | E1 (error) |
| 서술 | **메타서술 금지** — "Claude에게 시켰다", 커밋 해시·세션 언급 등. 연구자가 직접 한 일처럼 | M1 (error) |

## 서술 원칙 (METHOD에서 검증된 규칙)

1. 커밋은 "무엇을", 세션 프롬프트는 "왜"를 담는다 — 판단·의사결정·의문·발견을 살린다.
2. 수치·파라미터·파일명·식별자는 보존, 일반론은 제거.
3. 원인을 알아낸 실패도 기록 가치가 있다.
4. 남길 것: 발견·결정·근본 원인·수치·식별자. 먼저 버릴 것: 배경 설명, 반복, 수치 없는 수식어.

## 문체 (설정 `language`)

- `ko`: 한국어, 기술 용어·식별자만 원문
- `en`: terse research-log English
- `mixed`(권장): 기술 내용은 영문, `결정:` `원인:` `확인` `보류` 같은 짧은 한국어 마커 허용

## 버전

이 스펙은 v1이다. 형식 변경은 이 문서 갱신 + `src/note/` 파서·린터 + 골든 테스트 동반이 필수.
