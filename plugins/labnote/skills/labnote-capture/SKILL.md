# labnote-capture — 순간 기록

사용자가 방금의 발견·결정·실험 결과를 연구노트에 남기라고 하면:

1. **직전 대화에서 해당 내용을 정리한다** — 불릿 1~5개, 각 줄은 짧고 구체적으로.
   - 수치·파일명·명령·에러 메시지를 **원문 그대로** 보존한다.
   - 메타서술 금지("Claude가 ~했다", "사용자가 요청해서" 등) — 실험·작업 자체를 서술한다.
   - 사용자가 특정 문구로 남기라고 했으면 그 문구를 그대로 쓴다.
2. **저장한다** (현재 폴더로 과제가 자동 판별된다):

   ```bash
   printf '%s\n' "- 불릿1" "- 불릿2" | oln capture
   ```

   - 과제 판별이 안 되면 CLI가 에러로 알려준다 — 그때는 `oln capture -p <과제id>`로 지정 (`oln config`로 과제 목록 확인).
   - 다른 날짜의 일이면 `--date YYYY-MM-DD`.
   - `oln`이 없으면 `npx -y openlabnote capture`로 대신한다.
3. **짧게 확인해준다**: 무엇이 기록됐고, 그날 노트 정리(`oln today` 또는 /labnote) 때 반드시 반영된다는 것.
   노트가 이미 작성된 날이면 `oln today`에서 "새로 수집해서 다시 작성"을 고르면 흡수된다고 덧붙인다.

주제가 다른 여러 건이면 나눠서 여러 번 `oln capture` 한다. 기록 내용 외의 대화 맥락은 저장하지 않는다.
