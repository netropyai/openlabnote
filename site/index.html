연구노트, 쓰지 말고 만드세요

AI 코딩 세션의 프롬프트와 git 커밋이 이미 그날의 기록입니다. openlabnote가 그 기록을 모아 하루 한 장의 연구노트(md)로 정리합니다 — 당신의 Claude·Codex 구독으로, 추가 비용 없이.

$ npx openlabnote
$ oln today
① 수집 git 8커밋 · claude-code 12세션 → 과제 2건 매핑
② 작성 엔진 claude -p (41s)
③ 검사 통과 — 불릿 9 · 주제 3
✓ 저장 ~/openlabnote/neural-rendering/2026-08-21.md
$

기록은 이미 있습니다

01 · 수집세션과 커밋에서

Claude Code·Codex 세션, git 커밋을 날짜별로 수집합니다. 원격 개발 서버도 SSH로 — serverA:~/dev/repo. 결과 스크린샷·플롯 같은 그림 후보도 함께 찾습니다.

02 · 작성내 구독의 AI가 씁니다

요약·작성은 당신의 Claude/Codex 구독이 수행합니다. API 키도, 추가 비용도 없습니다. 커밋은 "무엇을", 프롬프트는 "왜"를 남깁니다.

03 · 검사·저장내 폴더의 마크다운으로

포맷 검사(oln lint)를 통과한 노트가 내가 지정한 폴더에 md로 쌓입니다. 웹 뷰어(oln ui)로 훑어보고, 제출용 PNG·PDF로 내보내세요(oln export).

이런 노트가 나옵니다

오른쪽은 openlabnote를 만든 날, openlabnote가 스스로 쓴 실제 노트입니다. 발견·결정·수치만 남기고 잡담은 버립니다 — 불릿 110자 제한, 하루 한 장.

형식 규칙(주제 ≤4 · 메타서술 금지 · 그림은 실존 파일만)은 공개 스펙 note-format v1이 정의하고 린터가 강제합니다.

세션 로그는 당신 컴퓨터를 떠나지 않습니다

raw는 로컬 전용

프롬프트 원문이 담긴 수집 데이터는 요약에만 쓰이고 어디로도 전송되지 않습니다. 밖으로 나가는 것은 완성된 노트뿐 — 그마저도 시크릿 스캔이 차단 게이트로 지킵니다.

내 구독으로 동작

별도 API 키·토큰 과금이 없습니다. 노트 작성은 이미 쓰고 있는 Claude Code / Codex 구독 안에서 일어납니다.

정부과제 증빙이 필요하다면

openlabnote는 무료로 완결됩니다. 다만 국가연구개발사업 전자연구노트는 세 가지를 요구합니다 — 기록자 전자서명, 시점 자동기록, 위·변조 확인. 그 세 가지가 OpenLabnote Cloud가 존재하는 이유입니다.

자주 묻는 질문

쓰고 있는 전자연구노트 서비스가 있는데 같이 쓸 수 있나요?

네. openlabnote는 노트를 만드는 도구라서 어디에 제출할지는 자유입니다. 노트는 md로 남고, oln export가 만든 일자별 PNG·기간 PDF를 쓰던 서비스에 그대로 올리면 됩니다.

세션 내용이 외부로 전송되나요?

아니요. raw 수집 데이터는 로컬에서만 읽혀 요약에 쓰입니다. 요약(작성) 자체도 당신의 하네스 구독 안에서 실행됩니다.

AI 사용 비용이 따로 드나요?

아니요. 이미 쓰는 Claude Code/Codex 구독으로 동작합니다. 노트 1건에 보통 30~60초의 세션이 쓰입니다.

이것만으로 지침상 전자연구노트가 되나요?

로컬 md는 훌륭한 기록이지만, 지침의 3요건(전자서명·시점기록·위변조 확인)은 별도 인프라가 필요합니다. 그 부분이 OpenLabnote Cloud(준비 중)이고, 그때까지는 export 산출물을 기존 서비스에 제출하는 방식을 권합니다.

노트 품질을 제가 통제할 수 있나요?

네. 작성 지침이 마크다운 파일이라 oln instructions write --edit로 내 문체·규칙으로 바꿀 수 있고, 포맷 린터가 형식을 강제합니다.
